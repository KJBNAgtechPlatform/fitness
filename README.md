# fitness

Each engineer opens an MR/PR that contains one file per workout:

Filename: 2025-11-30-firstname.md
Sample content:
......

date: 2025-12-04

duration: 42

activity: run

hr_avg: 155

hr_max: 179

strava: https://www.strava.com/activities/1234567890

Felt sluggish first 2 km, then negative-split the last 3 km.  
New PR on the 5 km segment 🎉.

......
# Key points
date, duration, activity are the only required fields.
hr_avg, hr_max, strava are optional—omit any you don’t want to share.
